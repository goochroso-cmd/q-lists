# 楽譜ビューア

iPadで楽譜（歌詞＋コード譜）のPDFを表示し、**曲ごとに決めた時間で自動スクロール**させるWebアプリです。
バンドの本番でステージ上に置いて使うことを想定しています。

- HTMLファイル1枚。ビルド不要・サーバー不要
- 一度開けばオフラインで動きます（ホーム画面に追加）
- 楽譜PDFと曲の設定は端末の中だけに保存されます。どこにも送信しません

## 使うところ

https://goochroso-cmd.github.io/gakufu-viewer/

iPadのSafariで開き、共有ボタン →「ホーム画面に追加」。
以後は機内モードでも動きます。

## できること

- セットリストを複数作り、曲を並べ替える
- 曲ごとにスクロール時間・向き（縦↓ / 横→ / 横←）・白黒反転を設定
- 演奏中はタップで開始／一時停止。指のドラッグで位置合わせ
- 曲の長さをストップウォッチで実測して自動入力
- セットリストと楽譜PDFをまるごと1ファイルに書き出し／読み込み（バックアップ）
- 演奏画面の操作バーを畳んで、楽譜を全画面で見られる

## 動作環境

iPad Air 2 / iPadOS 15 を基準に作っています。
pdf.js は legacy 版（3.11.174）を同梱しています。
